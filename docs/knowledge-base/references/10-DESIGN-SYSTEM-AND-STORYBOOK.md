## 🎨 Token Usage Rules
- **Strict Rule:** Never use raw hex colors (`#000000`) or raw pixel widths (`16px`).
- **Correct:** `background-color: var(--token-surface-primary);`, `padding: var(--token-spacing-md);`, `font-size: var(--token-text-base);`, `color: var(--token-text-primary);`, `border-radius: var(--token-radius-md);`.
