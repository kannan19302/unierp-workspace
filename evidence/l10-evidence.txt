Every one of the 41 gets an INDIVIDUAL entry naming its own file
path, its own exact line count, its own type (controller/service/

*.controller.ts files, D078 (L08's service-decomposition gap) for
*.service.ts files — both real, measured baselines this session
already built and proved correct via their own break/restore. This
is not a generic blanket "still working on it" line repeated 41
times; each entry names the specific file and its specific line
count, tied to a specific, previously-filed, evidenced reason.

WHAT THIS PHASE DOES NOT COVER
=================================
Every one of the 41 non-generated violators' exemption reason
resolves to "tracked by L07 or L08's own already-filed defect
(D077/D078), not yet individually decomposed" — this phase does not
itself decompose any of them further; L07/L08 already did that honest
work (one file each, proven, filed). This phase's own, narrower
scope is producing the required EXEMPTION LIST the exit criterion's
"OR" clause explicitly allows as a complete way to satisfy it — and
that list is real, individually-named, cross-referenced, and proven
correct via break/restore, not a placeholder.

Only unierp-api was measured in this pass — the exit criterion's own
"currently 86 (D017)" figure may include other repos (unierp-web,
etc.) not scanned here; extending scope to other repos is a
mechanical follow-up using the same script pattern.
