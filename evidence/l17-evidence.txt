L17 — Module orientation documents
Exit criterion: "Every module has one. A module whose orientation
document contradicts its code fails the documentation-truth gate
(A12). No hand-maintained duplication of what code already states."

BEFORE
======
$ node scripts/generate-module-orientation.mjs --check
FAIL  46 missing, 0 stale:
  MISSING: admin, advanced-finance, advanced-hr, ai, ... (all 46)
(no orientation document existed for any of the 46 real modules)

MECHANISM
=========
New scripts/generate-module-orientation.mjs generates
docs/module-orientation/<module>.md for every real module under
unierp-api/src/modules, purely from static analysis — no hand-written
content, so "no hand-maintained duplication" and "cannot drift" are
satisfied by construction:

  - What it owns: file/controller/service counts, real HTTP endpoint
    count (@Get/@Post/@Put/@Patch/@Delete).
  - Entities: every distinct prisma.<Model> reference in the module's
    own source.
  - Events emitted: every literal event-name string passed to
    .emit(...).
  - Permissions used: every literal string in a @Permissions(...)
    decorator.
  - Invariants: NOT mechanically derivable from source alone — left as
    an explicit, honest "needs review" placeholder rather than
    fabricated, matching this track's own established precedent
    (E01's row 15, L11's coverage-with-padding-removed section).

--check mode regenerates every module's doc IN MEMORY and diffs it
against the committed file — a document that disagrees with a fresh
regeneration is stale by definition. This IS the "documentation-truth
gate" the exit criterion names (A12's own general mechanism, applied
here specifically).

=============

the failure mode this gate exists to catch: a hand-maintained
document drifting from the code it describes.

WHAT THIS PHASE DOES NOT COVER
=================================
- The "invariants / what must never happen" section — explicitly
  named in the deliverable text — is NOT mechanically derivable and
  is left as a stated placeholder for every one of the 46 modules,
  not fabricated. A future phase populating this section for real
  would need a human (or a dedicated review-and-write phase) per
  module.
- Entities/events/permissions extraction is regex-based on literal
  string patterns (prisma.<Model>, .emit("literal"),
  @Permissions("literal")) — a dynamically-constructed event name or
  permission string (built via template literal or variable) would
  not be captured. A conservative, stated limitation, not claimed
  exhaustive.
